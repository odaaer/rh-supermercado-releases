# RH — Releases

Instaladores do sistema de Recursos Humanos do Mercado Campo Alegre.

O código-fonte fica em repositório privado. Aqui ficam apenas os binários,
para que o aplicativo instalado possa se atualizar sozinho sem precisar de
credencial do GitHub embutida no instalador.

## Instalar

Baixe o `RH-Setup-x.y.z.exe` da versão mais recente em
[Releases](https://github.com/odaaer/rh-supermercado-releases/releases)
e execute. A instalação não pede senha de administrador.

## Atualizar

O próprio aplicativo avisa quando há versão nova:
**Configurações → Geral → Verificar atualização**.
